### Automatic data abstraction

This repository contains the data and codes used for assessing the automatic data 
abstraction pipeline.

<a href="/data">/data</a> contains all the data sets used.

<a href="/ie_data/paper_pdfs">/pdfs</a> contains all the public literature on anopheles funestus that was filtered for this study.

The cleanned automactically extracted data can be found in <a href="data/auto_strict.csv">data/auto_strict.csv</a> and <a href="data/auto_geocoded.csv">data/auto_geocoded.csv</a>.

The manually extracted data derived from the <a href="https://vectoratlas.icipe.org" target="_blank">vector atlas platform</a> can be found in <a href="data/filteredData-VA/va_data_1790492525575.csv">data/filteredData-VA/va_data_1790492525575.csv</a>
